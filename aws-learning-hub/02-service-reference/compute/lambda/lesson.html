AWS Lambda

Nhớ một câu: chạy code theo event, không quản server.

Chọn Lambda khi nào?

Xử lý S3 upload, API nhỏ, lịch chạy, automation và tải không đều. Thời gian chạy tối đa 15 phút.

Scenario

Upload ảnh vào S3 rồi tạo thumbnail: dùng S3 event gọi Lambda. Lambda cần execution role để đọc/ghi S3.

Tự kiểm tra

Code Lambda truy cập DynamoDB bằng gì? → IAM execution role, không hard-code access key.
