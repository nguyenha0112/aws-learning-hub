EBS & EFS

EBS = block disk cho EC2
Boot volume, database volume; thường gắn trong một AZ. Backup bằng snapshot.
EFS = file system dùng chung
Nhiều EC2/Linux containers ở nhiều AZ cùng mount qua NFS.

Quyết định 10 giây

Một server cần disk bền vững → EBS.
Nhiều web servers cùng dùng thư mục upload → EFS.
Static images/download/archive → S3.

Tự kiểm tra

Client truy cập EFS trên port nào? → NFS TCP 2049, được cho phép bởi security group.
