# Nguồn bộ đề luyện thi

Tài liệu DOCX gốc nằm trong `source/`. Chạy lệnh sau từ thư mục gốc để xây dựng dữ liệu website:

```powershell
python scripts/import-practice-exams.py
```

Mọi bộ đề phải có 65 câu, bốn đáp án A–D mỗi câu và phần đáp án ở cuối tài liệu. Các bộ có câu hỏi/giải thích dạng placeholder được hiển thị cảnh báo để tránh dùng chúng làm tài liệu ôn tập chính thức.
