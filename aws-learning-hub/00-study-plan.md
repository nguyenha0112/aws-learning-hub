# Lộ trình học AWS: từ nền tảng đến làm đề

## Cách học một service

1. Đọc `notes.md`: hiểu service giải quyết vấn đề gì.
2. Mở `lesson.html`: tự trả lời câu hỏi và scenario.
3. Làm lab nhỏ, ghi vào `03-practice-labs`.
4. Thêm câu mình sai vào `04-review/flashcards.md`.

## Thứ tự khuyến nghị

| Tuần | Chủ đề | Dịch vụ |
|---|---|---|
| 1 | Identity, account, networking | IAM, VPC, Route 53 |
| 2 | Compute và lưu trữ | EC2, Lambda, S3, EBS/EFS |
| 3 | Database và integration | RDS, DynamoDB, SQS, SNS |
| 4 | Edge, observability, governance | CloudFront, CloudWatch, CloudTrail |
| 5+ | Architecture scenarios | ALB, ASG, Multi-AZ, DR, cost optimization |

> Khi ôn thi, luôn tự hỏi: yêu cầu về availability, performance, security và cost là gì? AWS managed service nào giảm phần việc vận hành nhất?
