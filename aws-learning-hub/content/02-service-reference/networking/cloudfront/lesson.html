Amazon CloudFront

Nhớ một câu: CDN đưa nội dung đến edge gần người dùng.

User → Edge location (cache) → Origin (S3 / ALB / API)

Scenario

Ảnh/static site toàn cầu tải chậm → CloudFront trước S3. Giữ S3 private và cho CloudFront truy cập bằng OAC.

Tự kiểm tra

CloudFront có thay thế database hay ALB không? Không; nó cache/phân phối content từ origin.
