AWS CloudTrail

Nhớ một câu: ai đã gọi API nào, lúc nào và bằng identity nào?

Event history

Xem 90 ngày management events gần nhất trong một Region.

Trail

Ghi event liên tục đến S3 để lưu lâu dài; có thể gửi CloudWatch Logs để alert.

Phân biệt

Performance/CPU/log ứng dụng → CloudWatch. Audit API activity → CloudTrail.

Scenario

Điều tra ai đã xóa security group → tìm CloudTrail management event.
