# Management & Governance

- **CloudWatch**: metrics, logs, alarms, dashboards.
- **CloudTrail**: ai đã gọi API nào, khi nào.
- **AWS Config**: lịch sử cấu hình và đánh giá compliance.
- **AWS Organizations**: quản lý nhiều account, SCP.
- **Cost Explorer / Budgets**: phân tích và cảnh báo chi phí.

Nhầm lẫn phổ biến: CloudTrail theo dõi API activity; CloudWatch theo dõi vận hành (metric/log/alarm).
