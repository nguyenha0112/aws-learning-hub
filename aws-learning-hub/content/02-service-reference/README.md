# Service Reference

Tổ chức theo domain, không theo thứ tự bảng chữ cái, để dễ liên kết các dịch vụ trong một kiến trúc.

- `compute`: chạy ứng dụng
- `storage`: lưu object/file/block
- `database`: dữ liệu quan hệ và NoSQL
- `networking`: kết nối và phân phối traffic
- `security`: identity, quyền, audit
- `management-governance`: quan sát, cấu hình, chi phí

Mẫu mỗi service: `notes.md`, `lesson.html`, `labs.md`, `exam-tips.md` (thêm dần khi học).
