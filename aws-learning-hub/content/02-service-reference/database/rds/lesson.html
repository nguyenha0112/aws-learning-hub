Amazon RDS & Aurora

Nhớ một câu: database SQL managed.

Cần gì?Chọn gì?

Bẫy thi

Multi-AZ tạo standby để failover, không phải để read scaling. Với database production, đặt DB trong private subnets.

Scenario

Ứng dụng cần SQL transaction và tự failover khi một AZ lỗi → RDS Multi-AZ.
