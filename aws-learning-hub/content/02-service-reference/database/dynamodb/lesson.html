Amazon DynamoDB

Nhớ một câu: NoSQL serverless, nhanh ở quy mô lớn.

Thiết kế trước khi tạo table:
1. Liệt kê access patterns.
2. Chọn partition key phân bố đều.
3. Thêm sort key/GSI cho các query khác.

Chọn nhanh

Session, cart, profile với latency ms → DynamoDB.
SQL, joins, transaction phức tạp → RDS/Aurora.

Tự kiểm tra

Muốn kích hoạt code khi item thay đổi? → DynamoDB Streams + Lambda.
