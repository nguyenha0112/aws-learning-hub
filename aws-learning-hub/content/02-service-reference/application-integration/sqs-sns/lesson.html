SQS & SNS

SQS: Producer → Queue → Consumer

SNS fan-out: Publisher → Topic → SQS / Lambda / Email

Chọn service

SQS khi cần buffer và tách rời producer/consumer.
SNS khi một event cần broadcast đến nhiều nơi.
SNS → SQS khi cần fan-out bền vững.

Bẫy thi

Visibility timeout ngăn consumer khác xử lý cùng message trong lúc consumer hiện tại đang làm việc. DLQ giữ message thất bại để điều tra.
