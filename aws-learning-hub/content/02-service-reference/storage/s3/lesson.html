Amazon S3

Ý tưởng: kho lưu trữ object, gần như không giới hạn.

Quy tắc chọn nhanh:
Static content → S3 + CloudFront.
Chống xóa nhầm → Versioning (và có thể Object Lock).
Giảm chi phí dữ liệu cũ → Lifecycle + Glacier.

Tự kiểm tra

  1. S3 có phải file system POSIX không? Không — đó là object storage.
  2. Ai kiểm soát public access? Block Public Access + policy/IAM.
