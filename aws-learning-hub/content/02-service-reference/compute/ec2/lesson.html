Amazon EC2

Ý tưởng: máy chủ ảo có thể cấu hình trên AWS.

Nhớ bằng câu hỏi

Cần kiểm soát OS? → EC2. Cần scale web tier? → ALB + Auto Scaling Group. Cần disk bền vững cho một instance? → EBS.

Mini scenario

Ứng dụng web cần chịu lỗi một AZ và tải tăng đột biến. Kiến trúc cơ bản: ALB trải nhiều AZ, ASG với EC2 ở private subnets, database Multi-AZ.
