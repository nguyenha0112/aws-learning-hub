# AWS Certified Cloud Practitioner (CLF-C02)

## Mục tiêu

Nắm cloud concepts, security & compliance, công nghệ AWS và billing/pricing.

## Checklist học

- [ ] Shared Responsibility Model
- [ ] IAM: user, role, policy, MFA
- [ ] EC2, Lambda, ECS khác nhau khi nào
- [ ] S3 classes, EBS, EFS
- [ ] VPC, Route 53, CloudFront
- [ ] CloudWatch, CloudTrail, AWS Config
- [ ] Billing, Budgets, Cost Explorer, Support plans

## Chiến lược làm câu hỏi

Ưu tiên đáp án managed service, ít vận hành nhất, bảo mật mặc định tốt và phù hợp yêu cầu chi phí/độ trễ trong đề bài.
