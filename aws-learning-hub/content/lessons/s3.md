# Mục tiêu học tập

- Biết object storage khác EBS/EFS như thế nào.
- Bảo vệ bucket với Block Public Access, policy, encryption và versioning.

## S3 là gì?

S3 lưu object: static content, backup, log và data lake. S3 không phải file system POSIX. Một bucket chứa objects; access được kiểm soát qua IAM policy, bucket policy và các guardrail.

## Bảo mật và phục hồi

Giữ Block Public Access bật nếu không thật sự phải public. Dùng Versioning để phục hồi object bị xóa/ghi đè và Lifecycle để quản lý chi phí các version cũ. Chọn SSE-S3 hoặc SSE-KMS tùy yêu cầu kiểm soát key.

## Scenario kiến trúc

Static site toàn cầu: S3 làm origin private, CloudFront cache tại edge, Origin Access Control cho phép CloudFront đọc bucket. Không mở public bucket nếu không cần.

## Lab an toàn

1. Tạo bucket, bật Versioning.
2. Upload và ghi đè một file, rồi restore version cũ.
3. Tạo Lifecycle rule test cho noncurrent versions.
