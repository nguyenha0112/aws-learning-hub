# AWS Certified Solutions Architect – Associate (SAA-C03)

## Trọng tâm

- Thiết kế bảo mật (IAM least privilege, encryption, private subnet).
- Thiết kế resilient (Multi-AZ, Auto Scaling, load balancer, backup).
- Thiết kế hiệu năng (cache, CDN, database phù hợp).
- Tối ưu chi phí (lifecycle, Savings Plans, serverless khi tải không đều).

## Khung giải câu scenario

1. Gạch chân ràng buộc: RTO/RPO, latency, HA, compliance, ngân sách.
2. Loại phương án tự vận hành nếu AWS có managed service phù hợp.
3. Kiểm tra network path, quyền IAM và encryption.
4. Chọn phương án đạt đủ yêu cầu với ít thành phần vận hành nhất.

Xem service notes ở `../../02-service-reference` khi cần ôn từng mảng.
